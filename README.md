# DreamResolution prototype

A clickable prototype of DreamResolution, a thirty-night dream intention practice, with one-night intentions for things that come up in between. Open the published page and use the **Jump to** menu to visit any moment.

This is a design prototype, not the app. Nothing you type leaves your browser.

## The calm voice

The statement is read aloud by [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), an open-source neural voice, running in the browser with ONNX Runtime Web. Phrases from the suggestions are pre-rendered; anything typed is voiced on the spot after a one-time download of the voice files (about 140 MB). See `THIRD_PARTY_NOTICES.md`.
